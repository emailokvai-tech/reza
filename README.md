# Vulture Eyes (ভালচার আইস)

## 🚀 গিটহাবে পুশ ও Vercel অটো ডেপ্লয়মেন্ট নির্দেশিকা

### ধাপ ১: গিট রিপোজিটরিতে কোড পুশ করা
```bash
# ১. গিট ইনিশিয়ালাইজ ও মেইন ব্রাঞ্চ নিশ্চিত করুন
git init
git branch -M main

# ২. সকল ফাইল স্টেজিংয়ে যোগ করুন
git add .

# ৩. কমিট করুন
git commit -m "feat: update Vulture Eyes branding, UK license, and admin management panel"

# ৪. রিমোট রিপোজিটরি সেট করুন (YOUR_USERNAME এবং YOUR_REPO পরিবর্তন করুন)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# ৫. পুশ করুন
git push -u origin main
```

### ধাপ ২: Vercel-এ লাইভ অটোমেটিক ডেপ্লয়মেন্ট
১. **[vercel.com](https://vercel.com)**-এ আপনার গিটহাব একাউন্ট যুক্ত থাকলে, পুশ করার সাথে সাথে Vercel স্বয়ংক্রিয়ভাবে নতুন কোড বিল্ড ও লাইভ করে দেয়।
২. নতুন প্রজেক্ট হিসেবে যোগ করতে চাইলে Vercel-এ **Add New Project** ক্লিক করে এই রিপোজিটরিটি ইমপোর্ট করুন। `vercel.json` এবং SPA রাউটিং কনফিগারেশন স্বয়ংক্রিয়ভাবে কাজ করবে।
