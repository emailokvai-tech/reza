## 🚀 গিটহাবে পুশ করার নির্দেশিকা (Push to GitHub)

নিচের কমান্ডগুলো আপনার লোকাল টার্মিনালে চালিয়ে খুব সহজেই প্রজেক্টটি গিটহাবে আপলোড করতে পারবেন:

```bash
# ১. গিট ইনিশিয়ালাইজ করুন (প্রয়োজন হলে)
git init

# ২. মেইন ব্রাঞ্চ সেট করুন
git branch -M main

# ৩. সকল ফাইল স্টেজিংয়ে যুক্ত করুন
git add .

# ৪. ইনিশিয়াল কমিট করুন
git commit -m "Initial commit: দি ইনভেস্টিগেশন পত্রিকা ও ভেরসেল কনফিগারেশন"

# ৫. আপনার গিটহাব রিপোজিটরির রিমোট লিঙ্ক যুক্ত করুন
# (YOUR_USERNAME এবং YOUR_REPO এর স্থলে আপনার গিটহাব ইউজারনেম ও রিপো নাম দিন)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# ৬. গিটহাবে পুশ করুন
git push -u origin main
```

## ⚡ Vercel-এ ডেপ্লয় করার নির্দেশিকা (Deploy to Vercel)

এই প্রজেক্টটি Vercel-এর জন্য বিশেষভাবে প্রস্তুত করা হয়েছে (`vercel.json` এবং Serverless API ফাংশন সহ)।

### পদ্ধতি ১: Vercel ড্যাশবোর্ড থেকে (সবচেয়ে সহজ)
1. **[vercel.com](https://vercel.com)**-এ লগইন করুন।
2. **"Add New..."** -> **"Project"**-এ ক্লিক করুন।
3. আপনার গিটহাব একাউন্ট থেকে রিপোজিটরিটি সিলেক্ট করে **Import** করুন।
4. ফ্রেমওয়ার্ক হিসেবে **Vite** স্বয়ংক্রিয়ভাবে শনাক্ত হবে।
   - **Build Command:** `vite build`
   - **Output Directory:** `dist`
5. **Deploy** বাটনে ক্লিক করুন! কয়েক সেকেন্ডের মধ্যেই ওয়েবসাইট লাইভ হয়ে যাবে।

### পদ্ধতি ২: Vercel CLI দিয়ে (টার্মিনাল থেকে)
```bash
# ভেরসেল সিএলআই ইনস্টল করুন (যদি না থাকে)
npm i -g vercel

# প্রজেক্ট ফোল্ডার থেকে সরাসরি ডেপ্লয় করুন
vercel

# প্রোডাকশন ডেপ্লয়মেন্টের জন্য
vercel --prod
```

## ⚙️ এনভায়রনমেন্ট ভেরিয়েবল (Environment Variables - ঐচ্ছিক)

প্রজেক্টটি কোনো এক্সটার্নাল ডাটাবেজ ছাড়াও ইন-মেমোরি মোডে সুন্দরভাবে রান হয়। তবে আপনি চাইলে Vercel Project Settings > Environment Variables-এ PostgreSQL ডাটাবেজ ক্রেডেনশিয়াল যুক্ত করতে পারেন:

| ভেরিয়েবল নাম | বিবরণ |
|---|---|
| `SQL_HOST` | ক্লাউড এসকিউএল / পোস্টগ্রেস হোস্ট |
| `SQL_USER` | ডাটাবেজ ইউজারনেম |
| `SQL_PASSWORD` | ডাটাবেজ পাসওয়ার্ড |
| `SQL_DB_NAME` | ডাটাবেজের নাম |
